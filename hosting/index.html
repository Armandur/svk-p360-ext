Installationsguide – Microsoft Edge

Tillägget distribueras utanför Edge Add-ons Store och installeras som ett okomprimerat tillägg via utvecklarläge. Det tar ungefär en minut.
  1. Ladda ned ZIP-filen ovan och packa upp den till en mapp på din dator, t.ex. Dokument\svk-p360-ext.
    Flytta inte mappen efteråt – Edge behöver hitta den vid varje start.
  2. Öppna Tillägg i Edge: skriv edge://extensions i adressfältet och tryck Enter.
  3. Aktivera Utvecklarläge med reglaget uppe till vänster.
  4. Klicka på knappen "Läs in okomprimerat tillägg" som visas.
  5. Välj mappen du packade upp i steg 1 (den som innehåller manifest.json direkt).
  6. Klart! Tilläggsikonen visas i verktygsfältet. Om den är dold, klicka på pusselbitikonen och fäst tillägget.
Notera: Edge visar en notis om "tillägg i utvecklarläge" vid webbläsarstart. Klicka Inaktivera inte för att behålla tillägget aktiverat.

Installationsguide – Google Chrome

  1. Ladda ned och packa upp ZIP-filen till en fast mapp på din dator.
  2. Öppna chrome://extensions.
  3. Aktivera Utvecklarläge via reglaget uppe till höger.
  4. Klicka "Läs in okomprimerat tillägg" och välj mappen.

Uppdatera tillägget

När en ny version finns:

  1. Ladda ned och packa upp den nya ZIP-filen till samma mapp som du använde vid installationen (skriv över de gamla filerna).
  2. Öppna edge://extensions (eller chrome://extensions) och klicka på uppdateringsikonen (⟳) på tillägget, eller klicka Uppdatera högst upp på sidan.

För IT-administratörer – distribution via grupprincip

På domänanslutna datorer (Active Directory eller Intune/MDM) kan tillägget distribueras tyst via ExtensionInstallForcelist-policyn utan att användaren behöver göra något. Kontakta din IT-avdelning och hänvisa till Microsofts dokumentation om tilläggshantering .

En förpackad .crx-fil för enterprise-distribution medföljer varje release.
